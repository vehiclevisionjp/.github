# VehicleVision

**PMC Co., Ltd. — IT Solution Div.** · Japan

We develop applications that advance image recognition technology, and we build and share open-source software around [Pleasanter](https://pleasanter.org/), the open-source low-code platform.

[Website](https://www.vehiclevision.jp/) · [YouTube](https://www.youtube.com/@vehiclevisionjp) · [Documentation](https://vehiclevisionjp.github.io)

## Contributing

Contributions are welcome. Please open an issue to discuss a bug or an idea before sending a pull request, and check each repository's README and license for project-specific guidance.

- **Bugs and feature requests:** open an issue in the relevant repository.
- **Questions and discussion:** use the repository's Discussions tab if it is enabled, otherwise open an issue.
- **Security issues:** please do not file a public issue; contact us privately via the [website](https://www.vehiclevision.jp/).

## Licensing

Our projects are released under open-source licenses, mostly **AGPL-3.0** and **LGPL-2.1**, with some under **MIT**. The license is stated in each repository's `LICENSE` file.

## Language

Most of our code is written in C#/.NET. Documentation and discussions are primarily in Japanese; English is welcome in issues and pull requests.
