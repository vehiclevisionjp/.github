## 👋 About us

Under the **Vehicle Vision** brand, **PMC Co., Ltd.** develops **license plate recognition** and vehicle identification systems, from instant plate detection and reading to managing the recognition data — for car dealerships, entry/exit management, truck scales, and traffic surveys.

This organization is where **PMC Co., Ltd. IT Solution Div.** shares **open-source software**, mainly tools and libraries around [Pleasanter](https://pleasanter.org/), the open-source low-code platform.

## 🔧 What we build

| | |
| --- | --- |
| 🧩 **Pleasanter ecosystem** | Client libraries, extensions, and integration tools that extend Pleasanter. |
| 🤖 **AI & authentication** | An OAuth wrapper that exposes the Pleasanter MCP server as an organizational connector. |
| 📝 **Web applications** | Survey and form applications that use Pleasanter as their backend. |
| 🛠️ **Developer tools** | Utilities for operations, data handling, and hardware testing. |
